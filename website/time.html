One-time setup needed

The time clock needs its tables and the manager-approval functions in Supabase. It takes about a minute:

  1. Open your Supabase project → SQL Editor → New query.
  2. Paste and run supabase/timeclock.sql, then paste and run supabase/authorization.sql (ask Claude for them in the chat).
  3. Come back here, reload, and make yourself the first manager under Hours & team.
