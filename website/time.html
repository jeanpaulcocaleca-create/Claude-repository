One-time setup needed

The time clock keeps its data in two new tables that don't exist in Supabase yet. It takes about a minute to create them:

  1. Open your Supabase project → SQL Editor → New query.
  2. Paste the setup script — it's the file supabase/timeclock.sql in the project (or ask Claude for it in the chat).
  3. Press Run, then come back here and reload the page.
