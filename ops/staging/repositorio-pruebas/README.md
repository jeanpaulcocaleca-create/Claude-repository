# canopy-pruebas (repositorio del dueño para el SITIO DE PRUEBAS)

Este repositorio solo publica una copia de las páginas de Canopy OS conectada al proyecto de **PRUEBAS** de
Supabase, en `https://jeanpaulcocaleca-create.github.io/canopy-pruebas/`. Nunca toca el sitio del café ni la
base de producción.

Contenido (copiado de `ops/staging/repositorio-pruebas/` del repositorio de desarrollo):

- `.github/workflows/publicar-pruebas.yml`: botón "Run workflow" → elige la versión → publica.
- `poner-pruebas.py`: conecta las páginas con PRUEBAS; se niega si le dan los datos de producción.

Instalación paso a paso: `docs/PRUEBAS.md` del repositorio de desarrollo.
